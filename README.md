## Global UI Button Component

A reusable, accessible Button component is provided at `src/components/Button.jsx` for consistent UI actions.

### Usage

```jsx
import Button from './components/Button';

<Button onClick={handleClick} variant="primary">
  Click Me
</Button>
```

_Button_ supports variants: primary (default), secondary, success, error. It respects a modern, minimal, and light theme, is fully responsive, and is built for accessibility.
